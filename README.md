User Management System

A simple user registration and login system built using PHP, MySQL, HTML, CSS, and JavaScript.

 Features

- User Registration
- User Login
- Form Validation
- Password Hashing
- Password Verification
- Session Authentication
- Protected Dashboard
- Logout
- MySQL Database Connectivity

Technologies Used

- HTML
- CSS
- JavaScript
- PHP
  MySQL
 Laragon

Project Description

This project demonstrates a basic user authentication system where users can create an account, securely store their password in the database, log in, access a protected dashboard, and log out.

Database

The project uses MySQL for storing user information such as:

- Name
- Email
- Password
- Role
